# Character assets

The character models in this directory come from Quaternius' **Zombie Apocalypse Kit**:

- `human_shaun.gltf`: Shaun single-weapon playable character
- `zombie_basic.gltf`: Basic zombie enemy
- Source: https://quaternius.com/packs/zombieapocalypsekit.html
- License: CC0 1.0 Universal
- License text: https://creativecommons.org/publicdomain/zero/1.0/

The original pack includes rigged, textured, animated glTF characters. Files were renamed locally to make their gameplay roles explicit.
